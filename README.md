# 筋トレメニュー

自宅トレーニング向けの記録アプリ（PWA）。GitHub Pages で配信し、データは本人の Google スプレッドシートに保存する。

## 機能
- **ホーム**: 今日のおすすめメニュー（しばらくやっていない順）、今週の回数と目標、連続週数、18週ヒートマップ、最近の自己ベスト、体重
- **トレーニング**: ＋／−で重さ・回数を入力、セット完了で休憩タイマー（音・振動）、時間種目は3秒前カウント付きタイマー、前回の値を自動入力、自己ベスト更新の通知、画面スリープ防止、途中で閉じても再開可能
- **メニュー**: 重量／自重／時間の3種別、セット・回数・重さ・休憩秒、並べ替え・複製、自宅向けテンプレート3種
- **履歴**: 月ごとの一覧と詳細、削除
- **分析**: 種目ごとの推定1RM・最大重量・ボリューム（自重は回数、時間は秒）の推移、週ごとのセット数、体重グラフ
- オフラインでも記録でき、つながったときに自動で送信

## 構成
- 画面: このリポジトリ（静的ファイルのみ、ビルド不要）
- データ API: `AIomakase-LAB/gas-projects` の `projects/workout-menu`（Google Apps Script）
- 接続: Apps Script の `/exec` を開くとスプレッドシートの「設定」シートに接続コードが書かれる。それをアプリの初回画面に貼る。
  接続コードは API の URL と秘密キーを含むので、他人に渡さないこと。
